**Rule:** a quantile replaces the mean only if units short fall by more than the mean's seed-to-seed std, while units not used here (expired + redistributed), alerts sent and alerts per donation each rise by at most 10%. Among levels that pass, the fewest units short wins.

**Result:** no level passes; the Planner keeps planning on the mean. Default in `bloodbank/catalog.PLANNING_DEMAND_QUANTILE` at run time: mean.

The D45 cost column is the rule `evaluation/sensitivity.py` used to pick the outreach window (3× units short + units not used here). It is shown, not used, here: by it an upper quantile can look better, because it prices a unit short at three wasted donations. Which rule is right is a clinical judgement, not something this simulation can settle.

Detection recall is computed on the shortages that still happen, so with few left (an upper quantile prevents most) it is noisy and not comparable across rows; units short is the outcome to compare.

Simulated demand is Poisson by construction (`data/demand_process.py`), so the Poisson approximation fits this world exactly; real demand is usually overdispersed, which would make these quantiles too low.
